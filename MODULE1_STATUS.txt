DATABASE SCHEMA
================================================================================

Tables Created: 8

1. material_categories
   - id (PK), name, description, created_at, updated_at
   - Relationships: 1:M → materials

2. materials
   - id (PK), name, category_id (FK), batch, quantity, available, reserved
   - unit, yard_id (FK), location_id (FK), ship_id (FK), status
   - created_at, updated_at
   - Relationships: FK references to categories, yards, locations, ships

3. yards
   - id (PK), name, location, capacity, status (enum), created_at, updated_at
   - Relationships: 1:M → materials, locations, ships

4. storage_locations
   - id (PK), yard_id (FK), zone, aisle, bin, capacity, current_load
   - status (enum), created_at, updated_at
   - Relationships: FK → yards; 1:M → materials

5. ship_series
   - id (PK), name, description, design_spec, created_at, updated_at
   - Relationships: 1:M → ships

6. ships
   - id (PK), name, series_id (FK), yard_id (FK), build_status (enum)
   - build_progress, allocated_value, material_line_count
   - scheduled_launch, scheduled_commissioning, created_at, updated_at
   - Relationships: FK → series, yards; 1:M → materials

7. suppliers
   - id (PK), name, contact_person, contact_email, contact_phone
   - address, country, status (enum), notes, created_at, updated_at
   - Relationships: Future 1:M → purchase_orders

8. material_transactions
   - id (PK), material_id (FK), transaction_type (enum)
   - quantity, unit, from_location_id (FK), to_location_id (FK)
   - from_ship_id (FK), to_ship_id (FK), reference_id, actor, reason
   - status, created_at, updated_at
   - Relationships: FK references to materials, locations, ships

Status Enumerations:
- MaterialStatusEnum (Healthy, Low stock, Inspection, Reserved)
- YardStatusEnum (Active, Maintenance, Closed)
- StorageLocationStatusEnum (Available, Full, Maintenance, Restricted)
- ShipBuildStatusEnum (Planning through Commissioned)
- SupplierStatusEnum (Approved, Conditional, Probation, Inactive, Blocked)
- TransactionType (Receipt, Issuance, Transfer, Adjustment, Return, Scrap, etc.)
